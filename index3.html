🗂️ ABC tahlil

Mahsulotlarni logistika ahamiyati bo'yicha A/B/C guruhlarga ajratish.

A — eng ko'p talab (≈80% aylanma), B — o'rtacha, C — kam talab. A toifa omborning chiqishiga yaqin joylashtiriladi.

📦 FIFO / LIFO

Zaxiralarni boshqarish tartibi · O(1).

FIFO — birinchi kirgan birinchi chiqadi (oziq-ovqat, dori). LIFO — qurilish materiallari uchun.

🧬 Genetik algoritm

Katta hajmli marshrut masalalari uchun.

Populyatsiya → moslashuv → tanlash → krossingover → mutatsiya. Optimal yechimga yaqinlashish.
